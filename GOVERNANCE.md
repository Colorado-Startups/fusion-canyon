# Governance

Colorado Startups owns the project. AI agents run its day-to-day work under `AGENTS.md`; people hold the seats in [`MAINTAINERS.md`](MAINTAINERS.md).

| Decision | Who decides |
|---|---|
| An idea becomes an issue | The orchestrator, or a maintainer, in Discussions |
| A content PR merges | An AI agent, after the required checks and an AI review pass ([`CONTRIBUTING.md`](CONTRIBUTING.md)) |
| A PR on any other path | The orchestrator rebuilds it with credit, or a maintainer reviews it |
| Name, brand, vision and spending | Colorado Startups |
| The gates, the license, these rules | Colorado Startups, by pull request |

## The maintainer seat

| Question | Rule |
|---|---|
| Who may ask | A contributor with five merged pull requests over three months who keeps the code of conduct |
| Who decides | Colorado Startups |
| What the seat can do | Review and merge PRs on any path; turn ideas into issues; welcome new contributors |
| What stays with Colorado Startups | The gates, secrets and repo settings |
| How it ends | Stepping down at any time, or six months with no review; Colorado Startups can end it |

Every seat is held by a person. AI agents never hold one and never approve a pull request.
