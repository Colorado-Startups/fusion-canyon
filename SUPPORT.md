| Report conduct | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |
| See how the repo scores | The Quality, Speed and Consumption page and the Process page, linked from the README |
